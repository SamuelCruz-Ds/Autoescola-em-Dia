# Autoescola em Dia

Aplicativo de gestão para a secretaria de uma autoescola brasileira, em Electron, TypeScript, Bootstrap e MySQL. Há um modo demonstração local que não exige banco de dados.

```sh
npm ci
npm run dev
```

Use `npm test` para os testes automatizados e `npm run build` para verificar e compilar o projeto.

- [Instalação e MySQL](docs/instalacao.md)
- [Manual de operação, previsão e SMS](docs/manual.md)
- [Roteiro de validação](docs/validacao.md)
- [Arquitetura e agentes](docs/arquitetura.md)

Os agentes do OpenCode estão em `.opencode/agents`. O projeto é entregue como código-fonte, não como instalador executável.
