# Autoescola em Dia

- Comunicação e interface em português do Brasil. Código de aplicação em TypeScript estrito.
- Não inicie a implementação de uma etapa futura sem aprovação explícita. Não comite em nome do usuário.
- Mantenha o renderer isolado. Acesso a dados, validação e integrações pertencem ao processo principal.
- Não introduza dados pessoais reais, credenciais ou HTML de usuário no código, logs, fixtures ou commits.
- Rode `npm test` e `npm run build` antes de concluir uma alteração. Use `docs/arquitetura.md` para as convenções.
